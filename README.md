# ANIK8 Student Command Center

A small, self-contained interactive student productivity dashboard.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser (Chrome, Safari, Firefox, or Edge).
3. No installation, server, or internet connection is required.

## Features
- Add and complete missions with XP rewards
- XP, level, streak, task and focus-time stats
- 25-minute and 5-minute focus sessions
- Demo skill progress and achievement badges
- Saves progress in your browser using localStorage

## Notes
- This is a front-end demo. Data is stored only in the browser on the device where you open it.
- The streak and subject percentages are simple demo logic, not a cloud-synced account system.
